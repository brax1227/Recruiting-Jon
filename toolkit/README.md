# Cruit Lab — Evaluation Toolkit

The documents Cruit Lab actually delivers and runs on. Use them in order.

| # | Document | When it's used |
|---|---|---|
| 01 | [Client Intake Form](./01_CLIENT_INTAKE_FORM.md) | Before any evaluation — collect player info, film, goals, consent |
| 02 | [Film Evaluation Report](./02_FILM_EVALUATION_REPORT.md) | The Tier 1 deliverable — honest, film-backed breakdown + 90-day plan |
| 03 | [College Tier Rubric](./03_COLLEGE_TIER_RUBRIC.md) | The framework for the honest "where can I play?" read |
| 04 | [Recruiting Profile Worksheet](./04_RECRUITING_PROFILE_WORKSHEET.md) | The Tier 5 deliverable — profile, target list, outreach plan |

## How to use them
1. **Intake (01)** → player fills it out (mirror it in your online form).
2. **Evaluate (02)** → watch the film, grade traits, write the honest summary.
3. **Place (03)** → use the rubric to set a realistic level range.
4. **Recruit (04)** → for HS players, build the profile and outreach plan.

## Turning these into client-ready deliverables
- Keep these markdown files as your **master templates**.
- For a client, copy the file, fill it in, and export to PDF
  (any markdown editor, or paste into Google Docs and brand it).
- Add the logo + colors from `BRAND_IDENTITY.md` for a polished look.
